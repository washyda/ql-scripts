# 维护规则

## 提交要求

- `main` 分支中的 `scripts/*.ts` 应始终可被青龙直接执行。
- 不提交 JavaScript 构建产物、本地日志、缓存、密钥或真实账号数据。
- 删除或重命名任务文件属于破坏性变更，应提供订阅和定时任务迁移说明。
- 修改任务路径后同步修改脚本头的 `script-path` 和订阅文档。

## 检查清单

1. 任务头包含名称、说明、六段 cron 和正确路径。
2. 环境变量的必填性、格式和多账号分隔方式已文档化。
3. 新增依赖已写入 `package.json`、锁文件及青龙安装说明。
4. `npm run check` 全部通过。
5. 受影响任务可通过 `npx tsx scripts/<任务>.ts` 直接执行。
6. `git diff` 中没有生成的任务 `.js` 或敏感信息。

## 常见故障

- 未生成任务：检查白名单是否为 `^scripts/[^/]+\.ts$`。
- 相对导入失败：检查订阅的依赖文件是否包含 `^src/core/.*\.ts$`。
- 找不到 axios/moment：在青龙「依赖管理」安装对应 NodeJS 包。
- TypeScript 无法执行：确认青龙版本和基础镜像提供 `.ts` 任务执行器。
